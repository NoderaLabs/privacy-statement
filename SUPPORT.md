# Skinfolio Support

If you need help with Skinfolio, contact:

`noderalaboratories@gmail.com`

When contacting support, include:

- your device model
- iOS version
- Skinfolio app version
- a short description of the issue
- screenshots, if relevant

## Common help topics

### Importing a Steam inventory

Skinfolio works with public Steam inventories only.

If import is not working:

1. Open Steam profile privacy settings
2. Set your inventory visibility to `Public`
3. Try the import again using your Steam ID or public profile URL

### Estimated values

Market prices shown in Skinfolio are estimates based on available pricing data. They may differ from a live sale price at any exact moment.

### Widgets not updating

If a widget looks outdated:

1. Open Skinfolio once
2. Return to the Home Screen
3. Wait a moment for widget refresh
4. If needed, remove and add the widget again

### Supporter unlock

Supporter is a one-time optional purchase that helps cover hosting and API costs.

If you already purchased Supporter and it does not appear unlocked:

1. Open the Supporter page in the app
2. Tap `Restore Purchases`
3. Make sure you are signed into the same Apple ID used for the purchase

### Crashes or app issues

If the app crashes or behaves unexpectedly, send:

- the steps that caused the problem
- your iPhone model
- your iOS version
- the app version

## Response

We will do our best to respond as quickly as possible.
